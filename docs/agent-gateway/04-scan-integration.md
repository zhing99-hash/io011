# 文件扫描接入与验证

日期：2026-11-18｜范围：开发验证；不构成生产检测能力验收

## 能力与状态

本地工作进程通过 ClamAV `VERSIONCOMMANDS` 确认引擎与数据库版本、通过 `INSTREAM` 发送已计算摘要的文件字节。协议适配器只允许本机 TCP 或本地套接字；ClamAV TCP 自身没有认证或加密，不能暴露公网。协议依据：[ClamAV 官方协议文档](https://docs.clamav.net/manual/Usage/ClamdProtocol.html)。

文件由 `quarantined` 进入 `scanning`，先执行[受限格式检查](05-format-inspection.md)。格式拒绝则转为 `rejected`；病毒检测命中转为 `isolated`；连接失败、超时、未知响应转为 `scan_failed`；没有检出则转为 `review_required`，仍然不能交付。企业数据检查及完整 PDF 解析尚未实现，这里不提供手工修改为 passed 的入口。

审查记录保存文件摘要、策略版本、格式检查器版本及结果、引擎版本、开始/完成时间和明确状态。扫描前后再次校验本地文件，摘要或大小不符转为 `isolated`。每个文件一次只允许一个活动审查；60 秒后可由本地工作进程重新获取过期的扫描任务，旧任务结果不能覆盖新任务。新审查使用固定策略 `v2-antivirus-format`，旧记录不重写；用户配置策略和完整版本管理尚未实现。

## 本地手工验证步骤

1. 在企业受控环境自行安装并维护 ClamAV；病毒库更新由企业运维负责，安装和更新流程应结合该版本官方文档验证。
2. 将 clamd 绑定 `127.0.0.1`，或配置本地套接字；只授予受信工作进程访问权。不得将其明文端口映射公网。隔离目录和数据库同样需要操作系统权限限制。
3. 检查 clamd 的 INSTREAM 限额至少覆盖验证版允许的 2 MiB 文件，并配置超限/解析异常的检测策略。引擎报告 OK 不证明所有嵌套内容都已扫描；引擎限额、病毒库时效和受支持格式需要独立验收。
4. 在网关创建测试文件提交后，使用本地命令对指定文件执行扫描：

```powershell
node --preserve-symlinks --preserve-symlinks-main scripts/scan-file.mjs F:/path/gateway.sqlite F:/path/quarantine FILE_ID
```

默认连接 `127.0.0.1:3310`；可通过 `GATEWAY_CLAMD_PORT` 改本机端口，或通过 `GATEWAY_CLAMD_SOCKET` 指定绝对本地套接字路径。数据库和隔离目录必须已存在。命令执行的是运维操作，不是用户安装流程；不要将任意远程用户传入的路径交给该命令。

5. 用户可通过原有状态接口查看文件当前状态；没有下载原文、提交客户端扫描结果或直接放行接口。

## 验证结果及限制

自动化测试运行真实本机 TCP 连接，另一端为仅模拟 clamd 协议的测试服务。它用于验证分块传输、异常响应、检出状态、超时和文件替换处理，不具备病毒检测能力。当前没有在本机安装真实 ClamAV，因此尚未完成真实引擎、病毒库更新、EICAR 标准测试文件及安全沙箱验收。

本地扫描命令只是受限的开发入口，尚无常驻任务调度、服务隔离、生产访问认证、解析沙箱或交付流程。持久化的扫描状态与字节摘要不代替这些控制。`review_required` 文件后续必须经过受信格式与企业数据策略检查，并在真正交付时重新校验权限和文件内容。
