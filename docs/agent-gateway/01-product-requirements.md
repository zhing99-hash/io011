# 开源企业 AI 连接网关：产品需求说明书

版本：V0.1｜日期：2026-11-17｜状态：需求基线，工程验证尚未完成

## 1. 产品定位与目标

企业自行部署开源连接网关，员工通过 WorkBuddy、Codex 或 DeepSeek Harness 的插件/技能接入。网关统一提供身份、权限、MCP/API 接口、数据审查及受控交付；企业自行建设并管理 Agent、工作流和业务系统。平台不代替这些系统进行合同审核等业务决策。

**已确认：**每家企业独立部署；首期自带账号；文档支持 Markdown、PDF、XML、DOCX、XLSX，支持 API 表单；DOC/XLS 延后；网络传输加密；上传后由平台安全审查；客户端优先插件/技能安装。原有 Excel 协同平台文档是另一个产品范围，不自动纳入本项目。

**待验证的建议：**插件商店发布路径及认证兼容性、规模和文件上限、保留期限、开源许可证、支持的操作系统、模型及外网策略；不能视为已确认或已实现。

## 2. 范围与非目标

P0：自带账号与企业初始化；用户和角色；客户端授权及撤销；三客户端适配验证；目标系统登记；工具与 API；文件隔离、检查、交付；表单校验；权限和审计；部署配置、备份恢复。可按开发里程碑逐步交付，不代表所有能力已具备。

不构建通用 Agent 编排或工作流引擎、业务审批和业务数据库管理；不提供任意 SQL、Shell、任意 URL 请求；不支持多企业共用 SaaS 或跨企业共享；不开放旧版 DOC/XLS 或带宏 DOCM/XLSM；不宣称病毒扫描能证明文件绝对安全。

## 3. 角色与对象

| 角色 | 基本职责 |
| --- | --- |
| 企业管理员 | 创建账号、授权、登记连接、设置文件和审查策略；不默认获取全部文件内容 |
| 普通用户 | 登录、查看授权连接、提交及查询自己被授权的记录 |
| 安全管理员 | 查看隔离和检查结果；依据独立授权处理异常 |
| 下游系统账号 | 只接收明确授权的文件或表单，返回状态；不能继承用户全部权限 |

对象：用户、用户组、角色、客户端授权、下游连接、数据对接规则、提交、文件版本、审查记录、交付记录和审计事件。一个企业实例是一个独立安全边界；系统账号与自然人账号分开。

## 4. 功能需求与验收

| 编号 | 功能与规则 | 验收条件 |
| --- | --- | --- |
| FR-01 | 首次部署创建管理员；账号停用及时生效；密码由成熟认证组件安全处理 | 停用后新请求和交付前检查均拒绝；密码不以明文存储或记录 |
| FR-02 | 安装助手适配包，连接企业地址，登录并显示身份、权限和连接状态 | 每个指定客户端及锁定版本分别实测；安装不破坏原配置，支持退出及撤销 |
| FR-03 | 身份从经过验证的服务端认证上下文获取，用户、客户端及下游服务身份分离 | 修改请求里的用户 ID、角色或目标 ID 不增加权限 |
| FR-04 | 权限同时覆盖用户/组、动作、资源、数据类型、目标与数据范围；默认拒绝 | 无权用户不能提交、读取、下载、调用目标或通过状态接口推断他人记录 |
| FR-05 | 管理员登记目标系统、认证方式、允许操作及类型，限制目的地址 | 非授权目的地址、重定向及禁止的网络目的地不可绕过策略 |
| FR-06 | 文件进入私有隔离区，受限大小、数量及格式，记录不可变版本与摘要 | 审查完成前下游无法获取；文件内容变化必须产生新版本并重审 |
| FR-07 | 执行文件格式和内容检查、恶意扫描；XML 禁外部实体；Office 禁宏；检查失败不放行 | 类型伪装、扫描失败、超时、异常解析均不可交付；扫描不宣称零风险 |
| FR-08 | 表单按已登记 schema 校验字段、长度及目的；权限同文件 | 未知字段、类型错误、越权目标均拒绝；不执行用户输入 |
| FR-09 | 审查通过后交付前重新验证用户/授权、目标、文件版本与策略版本 | 审查期间撤权、禁用目标或内容更改时不得交付 |
| FR-10 | 可查询本人有权查看的状态；异步交付有重试与幂等机制 | 超时重试不重复产生业务效果；下游不可用显示失败/待重试 |
| FR-11 | 安全审计记录主体、客户端、动作、资源、策略、结果、时间和追踪号，不记凭证和文件全文 | 越权、隔离、交付、撤权等可追踪；审计访问受限 |
| FR-12 | 客户端、平台与下游默认 HTTPS/TLS，校验证书；文件与备份受控保存 | 非安全连接及证书错误不静默放行；恢复演练可验证 |

## 5. 安装和使用体验

邀请或企业地址 → 选择对应助手 → 通过受支持的插件入口安装 → 登录平台账号并确认授权 → 连接测试 → 展示当前身份及允许的操作。邀请码仅用于发现或建立邀请，不是长期凭证。Skill 说明如何调用工具，MCP 提供接口，插件负责注册与必要的认证集成；不假设单独一个 Skill 可修改所有客户端配置。

原生 OAuth 或插件能力按具体版本进行兼容测试。无法安全直连的客户端可引入最小本地桥接，并使用系统凭证存储；不支持时明确标记而非声称一键安装。测试目标：不要求普通用户编辑 JSON/YAML 或复制长期密钥；中位接入时间 5 分钟、自助成功率 90% 是试点目标而非保证。

## 6. 数据与安全状态

文件状态：`quarantined → scanning → passed | rejected | isolated | review_required | scan_failed`。只有 `passed` 且交付时权限、目标、文件摘要和策略版本仍有效才可交付；变更文件产生新版本。扫描异常、服务故障、超时及不可解析均不放行。扫描通过只表示通过已配置检查。

人工处理：普通格式问题可由获授权人员重新检查或重新提交；恶意检测命中及扫描不可用默认禁止直接放行。任何扩展的放行策略需单独设计并经企业明确启用。

交付状态：`pending → delivering → delivered | retryable_failure | permanent_failure`。提供幂等键、接收方去重契约及回执；仅在下游确认后标记 delivered，无法无条件保证跨系统恰好一次。

## 7. 文件、表单和外部 Agent

Markdown 当文本处理，安全渲染且不自动访问链接；PDF 禁止自动执行活动内容；DOCX/XLSX 禁宏和外部链接自动访问；XML 禁 DTD、外部实体及外部资源；表单采用允许字段的 schema，不将输入拼接为 SQL、Shell 或目标 URL。文件解析沙箱限制 CPU、内存、解压大小和网络访问。上传、下载凭证短期有效并限定对象和用途。

审查通过不代表文档真实、无未知恶意内容或没有提示词注入。下游 Agent 执行工具仍需独立授权。平台能控制交付给谁和交付什么，无法控制未受平台管理的接收方后续行为；企业需自行审查外部模型和数据保留政策。

## 8. 隐私、保留和管理

用户只能查看授权资源；安全管理员与企业管理员不因角色名称自动得到原文读取权限。企业管理员可配置文件和审计留存周期；默认期限待企业场景确定，删除时处理隔离区、正式区、临时下载及备份的生命周期；不得承诺立刻从不可变备份中抹除。单企业自部署并非端到端加密或零知识系统。

## 9. 验收场景与指标

用测试账号和无害样本测试三个客户端安装、同一账号身份一致、撤权立即阻断、越权和资源枚举拒绝、伪装文件/恶意样本隔离、扫描不可用不放行、XML 外连阻断、文件变更重审、下游禁用阻断、重复请求去重、断线恢复和备份恢复。对真实扫描效果记录引擎版本和样本，不能凭单一测试集推断检测率。

## 10. 尚待决策

许可证与商用策略；Windows/macOS/Linux 优先级及客户端具体版本；管理员密码重置和多因素认证；单文件/总容量与审查时间目标；审计与文件保留期限；离线部署和病毒库更新；高敏字段识别/脱敏规则；企业系统接入与网络白名单审批；目标试点及负责人。未决事项不作为已承诺实现。
