## 2. 本轮继续完成的部分

1. **入站 HTTPS：**独立证书配置，最低 TLS 1.2，无 HTTP 降级；Host/Origin 限制、请求大小/字段校验、接收超时和响应安全头。HTTP 开发夹具继续仅监听本机。
2. **入口限流：**按真实 TCP 来源、规范化账号与总请求限流，不信任 X-Forwarded-For；容量有上限，拒绝时给出 429/Retry-After。仅单进程内存实现，重启清空。
3. **账号维护：**本人改密、管理员重置、全部会话撤销、临时密码会话强制改密；新 scrypt 参数和旧参数登录升级。未实现邮件找回、MFA、最后管理员凭证丢失恢复和完整邀请流程。
4. **数据库升级：**对已记录的旧原型结构执行事务性增量升级，保留用户/审计；无地址旧目标停用，未来版本数据库拒绝降级。SQLite 仍用于单实例联调，不承诺正式 PostgreSQL 或高可用支持。
5. **标准 MCP：**使用锁定的官方 server/client/node SDK，四个查询工具；每请求独立服务并复查会话，目标实时按授权过滤，文件状态仅本人可读。支持平台 Bearer 联调会话和第 7 项预登记客户端 OAuth；上传和管理接口仍不能使用 MCP OAuth 令牌。
6. **运行命令：**配置文件、标准输入管理员初始化、HTTPS 服务启动与关闭；不输出密码或会话凭证，不提供默认管理员。
7. **浏览器 OAuth：**使用 oidc-provider@9.15.0；资源/授权发现、预登记客户端、S256 PKCE、授权页面、轮换刷新及撤销。协议状态在同一数据库加密保存，密钥分离；重启后可恢复。用户改密、重置、停用或撤销客户端时立即清除关联授权。当前只有 mcp:read，不能用来调用账号管理或上传接口；动态注册和三客户端实机仍待完成。
8. **客户端接入包：**共用本地 stdio 连接器和统一 Skill；生成 Codex portable 插件/可选 TOML、WorkBuddy MCP 配置、DeepSeek Harness 插件条目。工具发现不登录，首次调用才打开企业网页登录；随机回环回调、state/issuer 校验、同源 HTTPS、内存令牌和串行刷新。新增按收据校验的安全包清理，保留用户额外文件。仍依赖本项目和本机 Node、需人工导入，尚未达到一键发行安装。
9. **网页账号与连接管理：**启用 OAuth 后提供 `/account` 登录、改密、本人连接分页及撤销确认；临时密码可在原授权交互中更新后继续 PKCE 和用户确认。网页登录服务端期限 30 分钟，临时更新 10 分钟；签名 Cookie、Origin 和动作/目标/会话绑定 CSRF，登录与改密失败共享数据库锁定。新增 `GET /v1/connections`，不允许按用户 ID 枚举。浏览器视觉验收受当前桌面权限阻断，尚未通过。
10. **引导安装与回退：**终端选择助手和项目，展示变更后安装；也支持保存计划再应用。保留既有配置值、拒绝同名/路径/旧计划冲突、记录原配置备份，校验全部恢复来源后卸载，支持真实进程退出后的安全恢复；遇到用户新修改停止。Windows 验证访问规则保留及备份继承保护。补齐 Harness 分层补丁格式，生成 connector.patch.yml。依赖和运行路径仍绑定本机，不代表独立一键安装已达成。
